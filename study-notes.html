1. Purpose and semantic baseline

Specimen User need / communication purpose Native HTML used and why What remains without CSS
Action Lets users quickly view the latest order status and understand the next step. An anchor element is used because the action navigates the user directly to the order status result. The link still works and takes the user to the order status information even without CSS.
Selection/status Lets users choose a delivery option and clearly see which option is selected. Radio inputs are used because the user is choosing one option from a group of delivery choices. Without CSS, the radio buttons and their labels still show which option is selected.
Disclosure/confirmation Lets users open the order status details and view the confirmation information when they need it. The details and summary elements are used because they provide a built-in way to expand and collapse additional information. Without CSS, the details can still be opened and the confirmation text remains readable.

4. Motion and CSS explanation

Transition 1: The .action link transitions transform and box-shadow over 180ms with ease. Hover moves the control slightly upward and adds a shadow, providing quick visual feedback that the link is interactive.

Transition 2: The .action::after arrow transitions its transform over 180ms with ease. On hover or keyboard focus, the arrow shifts slightly to the right to reinforce the direction of the action.

Keyframe animation: The confirm-pulse animation runs once for 400ms when the details element is opened. It briefly scales the confirmation from its normal size to 1.03 and back to normal to draw attention to the successful result without creating continuous motion.

Why these properties? Transform and box-shadow were chosen because they provide noticeable interaction feedback without changing the page layout. Explicit properties are transitioned instead of using transition: all, which keeps the motion intentional and predictable.

Reduced-motion alternative: When prefers-reduced-motion: reduce is enabled, transition durations are reduced to nearly instant and the confirmation animation is removed. All important feedback remains available through text, borders, focus outlines, selected states, and the confirmation message.
