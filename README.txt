MODULE 6 MICROINTERACTION STUDY

Project Description:
This project is a study of three CSS microinteractions using an action control, a delivery selection/status component, and a disclosure/confirmation component. The interactions provide clear visual feedback for hover, focus, active, selected, and open states. The project also includes a short keyframe animation and a reduced-motion alternative.

The page was built using semantic HTML and CSS without JavaScript, animation libraries, or CSS frameworks. The interactions were designed so that important information remains available without relying only on animation or color.

Testing Notes:
- Tested keyboard navigation and visible focus states using the Tab and arrow keys.
- Tested pointer interactions to make sure important information was not available only on hover.
- Tested prefers-reduced-motion using Chrome DevTools.
- Tested the page at a narrow browser width and at 200% zoom.
- Tested the page with CSS unavailable to confirm the semantic HTML remained understandable and functional.
- Recorded the interactions in the Chrome DevTools Performance panel and confirmed that they remained smooth.
